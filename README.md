##  Overview

This repository contains my Machine Learning practice exercises, experiments, and implementations. It serves as a personal learning space where I explore fundamental concepts, algorithms, data preprocessing techniques, model evaluation, and real-world datasets.
The goal is to strengthen my understanding of Machine Learning through hands-on coding, continuous practice, and experimentation with different approaches and libraries such as NumPy, Pandas, Scikit-learn, Matplotlib, and TensorFlow/PyTorch when applicable.
